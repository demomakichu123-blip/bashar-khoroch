# বাসার খরচ — Bashar Khoroch

বাসার সব খরচ, ধার-বাকি আর জমার হিসাব রাখার অ্যাপ। একটাই ফাইল — কোনো সার্ভার লাগে না।

## যা আছে

- **খরচ** — বাজার, খাওয়া-দাওয়া, বুয়া, WiFi Bill, ময়লা বিল, গ্যাস, Current, বাসা ভাড়া, অন্যান্য
  - মাস বাছাই করে ওই মাসের মোট খরচ
  - ক্যাটাগরি অনুযায়ী ভাগ
  - খরচ add / edit / delete
- **ধার / বাকি** — কে কত টাকা ধার নিলো / দিলো
  - আংশিক পরিশোধ যোগ করলে বাকি অটো হিসাব হয়
  - "পাবো" (সবুজ) আর "দিতে হবে" আলাদা মোট
- **জমা** — কেউ তোমার কাছে টাকা জমা রাখলে তার হিসাব
  - কার টাকা, কত, কবে — লিখে রাখো
  - আংশিক ফেরত দিলে বাকি অটো হিসাব হয় ("আমার কাছে জমা আছে" মোট উপরে দেখায়)
- সব ডেটা ব্রাউজারের localStorage-এ থাকে — পেজ রিফ্রেশ করলেও মুছে না

## iPhone-এ অ্যাপ হিসেবে বসানো

App Store লাগবে না — এটা PWA (home screen app):

1. iPhone-এ **Safari** দিয়ে খুলো: https://demomakichu123-blip.github.io/bashar-khoroch/
2. নিচের **Share** বোতাম → **Add to Home Screen**
3. Home screen-এ সবুজ ৳ আইকন আসবে — ওটা খুললেই ফুলস্ক্রিন অ্যাপের মতো চলবে, অফলাইনেও খুলবে

Android-এও একইভাবে Chrome → Add to Home screen।

## আসল iOS অ্যাপ (Capacitor — Mac লাগবে)

`ios/` ফোল্ডারে আসল native iOS প্রজেক্ট আছে (Capacitor 8, app id `com.basharkhoroch.app`) — এটাই iPhone-এর আসল অ্যাপ।

Mac + Xcode থাকলে:
1. Repo clone করো, `npm install` দাও
2. `npm run sync` দাও (ওয়েব ফাইলগুলো iOS প্রজেক্টে কপি হবে)
3. `ios/App/App.xcworkspace` খুলে iPhone কানেক্ট করে **Run** চাপো

নোট: `.ipa` ফাইল শুধু Mac-এ Xcode দিয়ে বানানো যায় — এই Linux মেশিনে বানানো যায় না। ওয়েব অ্যাপে কিছু বদলালে root-এর ফাইল বদলে `npm run sync` দিয়ে আবার sync করো।
